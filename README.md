Скрещивание MTProxyMax https://github.com/SamNet-dev/MTProxyMax и Web-интерфейса Админ панели

Для правильной работы потребуется MTProxyMax.
Реализация работы выглядит таким образом:
1. Кнопки Web-интерфейса отвечают за исполнение команд в MTProxymax, например:
    mtproxymax secret remove (Для кнопки удалить)

2. Генерация ключей:
    **ee** - FakeTLS-маскировка, если нужно замаскировать под какой-нибудь сервис, он всегда будет ставиться в начале.
    **8xxxxxxxxxxxxxxxxxxxxxxxxxx75db** - 32 символьный ключ для пользователя, он уникальный для каждого user-a. Является ключом для "голого" MTPROTO
    **7477697463682e7476** - перевод в Hex домена под который будет офусцироваться трафик (на данном примере домен twitch.tv). Эти 18 символов всегда будут идти в конце.
    Таким образом получается ключ: **ee8**************************75db7477697463682e7476**
