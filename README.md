## ⚙️ Архитектура и принцип работы

Управление прокси-сервером осуществляется через интеграцию веб-панели с консольной утилитой **MTProxyMax**. Веб-интерфейс выступает в роли удобной графической оболочки (GUI), которая транслирует действия администратора в системные CLI-команды.

### Взаимодействие интерфейса и CLI
Каждое действие в панели отправляет соответствующий запрос на бэкенд, который выполняет низкоуровневую команду в контексте операционной системы. Например:
* **Удаление пользователя:** нажатие кнопки «Удалить» вызывает системную команду:
  ```bash
  mtproxymax secret remove <имя_пользователя>
  ```
* **Управление лимитами:** изменение ограничений через модальное окно транслируется в команды конфигурации сессий и IP-адресов:
  ```bash
  mtproxymax secret setlimit <имя_пользователя> ips <количество>
  ```

### 🔑 Алгоритм генерации ключей (Secret)

Для обеспечения максимальной безопасности и обхода систем глубокого анализа пакетов (DPI) панель генерирует сложные криптографические ключи с поддержкой **FakeTLS-маскировки**. 

Итоговый ключ пользователя формируется путем конкатенации трех независимых компонентов:

\[\text{Итоговый ключ} = \text{[Префикс FakeTLS]} + \text{[Уникальный токен]} + \text{[HEX-домен]}\]

#### Структура ключа на примере домена `twitch.tv`:

1. **Префикс маскировки (`ee`):**  
   Обязательный стартовый маркер, который сообщает клиенту (например, Telegram) и прокси-серверу о необходимости инкапсулировать трафик в легитимные TLS-пакеты для обхода блокировок. Всегда устанавливается в начало ключа.
   
2. **Уникальный токен пользователя (32 символа):**  
   Случайно сгенерированная шестнадцатеричная последовательность, выступающая в качестве классического ("голого") приватного ключа авторизации для протокола MTPROTO.  
   *Пример: `8xxxxxxxxxxxxxxxxxxxxxxxxxx75db`*

3. **HEX-кодированный домен (18+ символов):**  
   Доменное имя целевого веб-сервиса, под который будет визуально офусцироваться весь сетевой трафик. Домен преобразуется в формат HEX и всегда замыкает финальную строку ключа.  
   *Пример: `twitch.tv` \(\rightarrow\) `7477697463682e7476`*

#### 📝 Итоговый вид сформированного секрета:
```text
ee8xxxxxxxxxxxxxxxxxxxxxxxxxx75db7477697463682e7476
```
*(Где `ee` — префикс, `8...db` — приватный токен, `74...76` — маскировочный хвост Twitch)*
